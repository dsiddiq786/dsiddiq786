## Engineering Philosophy

**Build systems, not just prompts.**

Reliable AI applications need more than capable models. They need clear architecture, controlled tool access, meaningful context, evaluation, and failure handling.

My engineering principles are straightforward:

- Prefer maintainable architecture over unnecessary complexity.
- Give agents relevant context instead of unlimited information.
- Separate model-generated decisions from authorized actions.
- Make execution observable and failures diagnosable.
- Evaluate outputs and workflows against measurable requirements.
- Design software for real operational environments.
